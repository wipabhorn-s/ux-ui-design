⚠️ Error States

Reusable UI error patterns. No backend logic — display-only components for common failure scenarios.

🔐
Login Failed
อีเมลหรือรหัสผ่านไม่ถูกต้อง กรุณาตรวจสอบและลองอีกครั้ง
💳
Payment Failed
ธุรกรรมถูกปฏิเสธ ยอดเงินในบัตรอาจไม่เพียงพอ
📡
Network Error
ไม่สามารถเชื่อมต่ออินเทอร์เน็ตได้ ตรวจสอบการเชื่อมต่อของคุณ
🔥
Server Error (500)
เซิร์ฟเวอร์เกิดข้อผิดพลาด ทีมงานกำลังแก้ไขปัญหา
🚫
Access Denied
คุณไม่มีสิทธิ์เข้าถึงหน้านี้ กรุณาเข้าสู่ระบบก่อน
⏰
Course Expired
สิทธิ์เข้าถึงคอร์สนี้หมดอายุแล้ว ต่ออายุเพื่อเรียนต่อ
🔍
No Data Found
ไม่พบข้อมูลที่ค้นหา ลองเปลี่ยนคำค้นหาแล้วลองใหม่
📁
File Upload Error
ไฟล์ใหญ่เกินไปหรือรูปแบบไม่รองรับ (สูงสุด 2MB, PNG/JPG)
⚙️
System Error
